# 🗳️ EVM Voting System

A **web-based electronic voting application** developed using Python Flask and MySQL, designed to provide a simple and reliable voting experience.

## 🚀 Features

* Secure voter authentication
* Duplicate-vote prevention
* Candidate selection and validation
* Automated vote counting
* Admin authentication
* Real-time election results
* Cloud-based MySQL database

## 🛠️ Technologies

**Python • Flask • MySQL • HTML • CSS • Aiven**

## ⚙️ How It Works

Voters submit their Voter ID and select a candidate. The system validates the voter, records the vote in the database, and automatically updates the candidate's vote count. Administrators can securely access the results dashboard.

## 🎯 Objective

The project demonstrates the practical implementation of **web development, database management, authentication, and backend integration** in a real-world voting application.
